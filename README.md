## Om mig

Nyutexaminerad DevOps Engineer (YH, 2026) som gillar att bygga saker som fungerar i produktion – inte bara i teorin.

Under mitt examensarbete på **Cloudist AB** designade och driftsatte jag en komplett **GitOps-baserad Internal Developer Platform** för observability på Kubernetes. Plattformen inkluderade:

- Full **LGTM-stack** (Prometheus, Loki, Tempo, Grafana)
- Multi-miljösetup (base / staging / production) med **FluxCD**, **Kustomize** och **Helm**
- Säker extern åtkomst via Traefik + automatiserad TLS med cert-manager

På fritiden bygger jag vidare med Terraform och Kubernetes för att fördjupa mig i Infrastructure as Code och GitOps.

Innan tech arbetade jag flera år inom offentlig sektor, bland annat som studie- och yrkesvägledare. Det gav mig något jag ser många teknikprofiler sakna: förmågan att förklara komplexa system för icke-tekniska personer och strukturera arbete som annars blir rörigt.
